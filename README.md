# e-plantShopping

## Project: Plant Shopping App

e-plantShopping is a web application for plant shopping built with React and Vite.

### Description
This application allows users to browse different plants, add them to a shopping cart, and manage their selections through a simple and interactive interface.

### Technologies Used
- React
- Vite
- JavaScript
- CSS

### Main Features
- Browse a plant catalog
- Add plants to the shopping cart
- Manage cart items
